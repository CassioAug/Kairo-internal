# Kairo Bug Sweep - 2026-05-19

Branch: `audit-bug-sweep-2026-05-19`

Status key:

- `[ ]` Open
- `[x]` Fixed in this branch

Verification note: this pass intentionally avoids running tests or compiling unless that constraint is explicitly changed.

## Critical

- [x] Auto Backup can upload imported book/article content.
  - Evidence: `AndroidManifest.xml`, `backup_rules.xml`, `Entities.kt`
  - Fix target: exclude sensitive book/article database content from Android backup or make backup posture explicit.
- [x] RSVP preview frames can be treated as final playback.
  - Evidence: `RsvpFrameRepository.kt`, `RsvpFrameRepositoryImpl.kt`, `RsvpScreen.kt`, `RsvpScreenEffects.kt`
  - Fix target: distinguish preview frames from complete frame sets and block finish/save from preview-only data.
- [x] Import jobs are composition-scoped and can be lost on rotation/recreation.
  - Evidence: `KairoNavHost.kt`, `ImportCoordinator.kt`
  - Fix target: move import work/state to a lifecycle-stable owner and consume external intents only after durable queueing.

## High

- [ ] Reader chapter loads can race and commit stale chapter data.
  - Evidence: `ReaderViewModel.kt`
  - Fix target: discard stale async chapter loads before committing UI state.
- [ ] Missing/deleted book routes spin forever.
  - Evidence: `ReaderRoute.kt`
  - Fix target: show a recoverable missing-book error instead of an infinite loader.
- [x] Bookmark query can still load oversized cover blobs.
  - Evidence: `BookDao.kt`, `BookmarkDao.kt`
  - Fix target: apply the same cover-size guard to bookmark book rows.
- [x] Unreadable imports can be persisted as successful placeholder books.
  - Evidence: `EpubBookParser.kt`, `MobiBookParser.kt`, `MobiFallbackParser.kt`
  - Fix target: fail import when extracted readable content is below a useful threshold.
- [x] Book deletion is not atomic.
  - Evidence: `LibraryRepositoryImpl.kt`, `Entities.kt`
  - Fix target: perform DB deletion in a transaction and keep asset cleanup consistent.
- [x] Backup restore is incomplete for illustrated books and preferences.
  - Evidence: `backup_rules.xml`, `data_extraction_rules.xml`, `EpubBookParser.kt`, `MobiImageProcessor.kt`, `PreferencesRepositoryImpl.kt`
  - Fix target: align backup includes/excludes for DB, asset folders, and DataStore.
- [x] Valid files can be rejected when display-name extension conflicts with MIME.
  - Evidence: `BookRepositoryImpl.kt`
  - Fix target: choose parsers from ordered supported extension candidates, not display name alone.
- [x] Background token prefetch can leak uncaught failures.
  - Evidence: `TokenRepositoryImpl.kt`
  - Fix target: catch/log the whole speculative prefetch body.
- [ ] First-run tutorial can skip Reader/RSVP steps due async launch context.
  - Evidence: `StartingTutorialCoordinator.kt`, `KairoApplication.kt`
  - Fix target: wait for initial tutorial launch context before auto-starting the tutorial.

## Medium

- [ ] Reader route may save stale RSVP result position after cross-chapter return.
  - Evidence: `ReaderRoute.kt`
  - Fix target: save position only after target chapter data can map the RSVP token.
- [ ] Reader chapter/token failures become generic empty content.
  - Evidence: `ReaderViewModel.kt`, `ReaderContent.kt`
  - Fix target: surface a real chapter-load error state.
- [ ] Page-number stripping can remove legitimate numeric-only lines.
  - Evidence: `Tokenizer.kt`, `PageNumberHeuristics.kt`
  - Fix target: strip only stronger page-number candidates.
- [ ] HTML block extraction can reorder images after text.
  - Evidence: `ReaderViewModel.kt`
  - Fix target: preserve source order for text and image markers.
- [ ] Settings home is not scrollable on small/large-font screens.
  - Evidence: `SettingsHomeScreen.kt`
  - Fix target: make the page vertically scrollable with safe bottom padding.
- [ ] Reader token/link interactions lack accessible actions.
  - Evidence: `ReaderScreenParagraph.kt`
  - Fix target: expose focus/start and link actions through semantics or accessible controls.
- [ ] HTTP article URLs are accepted but cleartext is not configured.
  - Evidence: `WebArticleUrl.kt`, `WebArticleExtractor.kt`, `AndroidManifest.xml`
  - Fix target: reject/upgrade HTTP or intentionally configure cleartext.
- [ ] In-app language choice may not persist on Android 12 and lower.
  - Evidence: `libs.versions.toml`, `LanguageSettingsScreen.kt`, `AndroidManifest.xml`
  - Fix target: add AppCompat locale storage or app-managed locale persistence.
